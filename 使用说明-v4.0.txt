========================================================
  全能媒体反推 · 商用版 v4.0  使用说明
========================================================

一、这是什么
--------------------------------------------------------
把图片、视频交给视觉大模型，自动反推出可直接复用的提示词（Prompt）。
适合：AI 绘画/视频创作者的素材反推、电商与设计团队的风格拆解、
素材库批量打标、竞品画面拆解与二次创作。

核心能力
· 批量处理：一次拖入任意数量的图片/视频，或直接扫描整个文件夹
· 自动识别类型：图片走图片提示词，视频自动抽帧拼图后分析
· 并发可调（1-8）：任务越快越省时间，额度紧张时可降到 1-2 避免限流
· 可暂停 / 继续 / 取消 / 失败重试，中断任务重启后可续上
· 30 套内置提示词预设，按场景分组：
    通用（5）：标准反推、英文提示词、细节长描述、极简一句、反向提示词
    人像 / 服饰（4）：人像摄影、全身照姿势复刻、服装穿搭拆解、妆容发型
    电商 / 产品（3）：电商产品图、白底主图、美食摄影
    空间 / 建筑（2）：建筑外观、室内设计
    插画 / 游戏（3）：二次元动漫、3D 游戏美术、扁平矢量
    影像 / 风格（4）：风格解析、电影感镜头、光影布光、胶片质感
    平面 / 文字（3）：海报排版、Logo 图标、文字提取
    质检 / 修复（2）：画质质检、高清放大参考
    视频（4）：视频分镜、短视频带货脚本、视频生成提示词、运镜复刻
· 主界面可随时「自定义」本次提示词（不改预设），一键存为「我的预设」
· 图片和视频可分别选预设、分别填提示词，自动识别素材类型分别套用
· 自定义预设保存在本地 config.json，重启不丢
· 结果导出 TXT（每条提示词一行，可直接整段复制）/ CSV / 清单压缩包，同时自动写入「输出」文件夹
· 本地任务历史，随时回看、复制、单项重跑

二、免安装版怎么用（推荐）
--------------------------------------------------------
1. 解压整个「全能媒体反推」文件夹（不要只把 exe 单独拖出来，
   exe 依赖同目录的 _internal 文件夹）。
2. 双击「全能媒体反推.exe」。
3. 程序会自动打开浏览器（默认 http://127.0.0.1:8888/）。
   如果 8888 被占用，会自动顺延到 8889、8890 …… 以控制台窗口显示的地址为准。
4. 首次使用会弹出「设置」：选服务商 → 填 API Key → 点「测试连接」→ 保存。
5. 拖入素材，点「开始批量反推」。

【第一次用建议先自检】
双击同目录的「自检.bat」→ 浏览器自动打开「设置 → 自检」，
9 项逐条检查并给出修法（全绿再开跑）：
  配置文件 / 接口地址 / API Key / 模型列表 / 模型可用性 /
  输出目录 / 磁盘空间 / 接口实测（文字）/ 接口实测（看图）
含「看图」实测，会真发一张 64×64 小图，消耗极少额度。

关闭：直接关掉黑色控制台窗口即可。

三、接口怎么配
--------------------------------------------------------
程序走 OpenAI 兼容的 /chat/completions 协议。打开「设置 → 接口」，
点对应卡片就会自动填好接口地址和模型，只需补自己的 API Key：

              https://cloud.siliconflow.cn/i/9VTziPIQ
· 智谱 AI     https://open.bigmodel.cn/api/paas/v4
              模型 glm-5.3-flash（原生多模态，1M 上下文）  注册送 2 亿 Tokens
              https://www.bigmodel.cn/invite?icode=XG%2FAr2D7pjbGwf3MI83HHWczbXFgPRGIalpycrEwJ28%3D
· 魔塔社区    https://api-inference.modelscope.cn/v1
              模型 Qwen/Qwen3-VL-32B-Instruct       每天送 200 魔力，注册再送 50
              https://www.modelscope.cn/register?inviteCode=asy666&invitorName=asy666
· 七牛云      https://api.qnaigc.com/v1
              模型 qwen/qwen4-max（图文视频都能读）  注册送 300 万 Token
              https://s.qiniu.com/eEJNBn

另有两个通用入口：
· 通用接口 —— 清空表单，自己填任意 OpenAI 兼容的 Base URL（一般以 /v1 结尾）
· 本地 AI 通用接口 —— 不限端口，任何 OpenAI 兼容的本地服务都能接：
    地址格式 http://127.0.0.1:<端口>/v1，端口按你装的软件来：
      Ollama 11434 · LM Studio 1234 · llama.cpp(llama-server) 8080 · vLLM 8000
    设置里已放好这 4 个端口按钮，也可点「检测本机服务」自动扫一遍，
    扫到就把地址和模型一起填好（扫不到会提示你先启动服务）。
  · Key 可以留空：本机 / localhost / 内网地址不校验密钥；公网 http 地址仍需填 Key
  · 模型名填你本地已下载的视觉模型（ollama list 里能看到，如 qwen2.5vl:7b）
  · 局域网共用：把 127.0.0.1 换成那台机器 IP，例如 http://192.168.1.8:11434/v1
  · 本地模型慢，建议把「超时」调到 600 秒；显存不够 7B 起步更稳

模型不用自己抄：填完 Key（或本地地址）后，程序会自动拉取这个接口下的
全部可用模型，逐个标注「视觉 / 文本」，并自动帮你选中最合适的视觉模型。
· 想手动换：点「拉取可用模型」，在列表里按「图片」「视频」按钮即可分别指定
· 列表上方有搜索框，模型多的时候直接搜 vl / qwen / glm
· 标「视觉」的才能反推图片和视频；纯文本模型选了会在开跑前被拦下
· 前 3 个视觉模型带「推荐」标记，是程序按能力排序选出来的
· 拉不到列表（服务商没开放 /models）会自动列出推荐模型，也可以手填模型名

开跑前程序会做一次体检：地址、Key、模型任何一项不对，会直接提示原因，
不会让你等几百个文件全跑失败才发现。

「测试连接」不消耗额度，只发一句 hi 验证通不通。
切换服务商时记得同时换 Key，Key 与地址必须属于同一家。

四、参数怎么调
--------------------------------------------------------
图片最长边 1600px   —— 越大细节越多、token 越贵，一般 1600 够用
JPEG 质量 88        —— 压缩质量，低于 70 会损失细节
视频抽帧数 9        —— 视频默认抽 9 帧拼成一张触点图，速度最快
视频抽帧拼图         —— 关闭后改为逐帧直传，更准但慢很多、更贵
超时 600 秒          —— 可自定义 10–7200 秒（最长 2 小时），
                        300/600/1200/3600 有快捷按钮；本地大模型慢就往上加
失败重试 3 次        —— 遇到 5xx/超时会自动退避重试，可设 1–8 次

五、结果在哪
--------------------------------------------------------
· 界面里：任务面板右侧逐条查看/复制，可导出 TXT、CSV、ZIP
· 硬盘上：程序目录下的「输出」文件夹，每次任务一个子目录：
    输出/20251125_143012_我的任务/
         01_xxx.jpg.txt
         02_xxx.mp4.txt
         results.csv
         results.json
· 勾选「结果存到源文件目录」后，txt 会直接和原图放一起，
  批量整理素材时更好用；勾选「跳过已有结果」可避免重复花钱。

六、常见问题
--------------------------------------------------------
Q：杀毒软件报毒 / 拦截？
A：PyInstaller 打包的程序常被误报，加白名单/信任即可；
   也可以改用「源码版」自己跑（见第七节）。

Q：提示「未配置 API Key」？
A：右上角「设置」→ 接口 → 填 Key → 测试连接 → 保存。

Q：不知道哪一步配错了？
A：双击「自检.bat」，9 项逐条检查，没过的会直接写「修法」。
   常见：401=Key 不对；404=模型名或地址不对；超时=调大超时/降并发。

Q：批量跑一半大面积失败，日志里 429？
A：服务商限流。把并发降到 1-2，或在设置里把重试次数提高到 5。

Q：视频分析很慢？
A：确认设置里「视频抽帧拼图」是开启状态；关闭会慢 5-10 倍。

Q：浏览器没自动打开？
A：手动复制控制台里的地址粘贴到浏览器。

Q：想换台电脑 / 多人共用？
A：整个文件夹拷走即可。config.json、results.db 都在程序目录，
   属于本地数据，只把素材发给你配置的模型服务商。

七、源码版（给想改代码/二次开发的人）
--------------------------------------------------------
要求：Windows + Python 3.10 以上（推荐 3.12）
1. 双击 start_simple.bat —— 首次会自动建 .venv 并装依赖，之后直接启动。
2. 目录结构：
     run.py              启动入口（端口顺延 + 自动开浏览器）
     webapp/config.py    配置、路径、内置预设
     webapp/client.py    模型接口客户端（重试/限流/错误分类）
     webapp/media.py     图片压缩、视频抽帧、缩略图、拼图
     webapp/store.py     本地任务库（SQLite）
     webapp/jobs.py      任务调度、并发、暂停/取消/重试
     webapp/main.py      HTTP 接口
     webapp/templates/   页面
     webapp/static/      样式与脚本
3. 想重新打包：双击 build.bat，产物在 dist\全能媒体反推\。

八、数据与隐私
--------------------------------------------------------
· 所有任务记录、配置只存在本机（config.json / results.db / uploads）。
· 图片视频只会发送到你自己配置的模型接口，不经过第三方中转。
· uploads 里是临时上传副本，48 小时未动的会自动清理；
  也可以手动删 uploads 目录，不影响历史结果文本。

九、给客户的一页纸
--------------------------------------------------------
· 「客户速查卡-A4.pdf」是打印/发客户用的一页版：
  三步开跑、6 种接口、关键参数、报错对照表、自检与交付。
· 「自检.bat」双击即用，不需要客户懂命令行。
· 交付时把整个文件夹 + 速查卡一起打包，对方解压双击即可。
